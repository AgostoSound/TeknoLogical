# TL-tester

TL-tester is a development-only panel used on the `with-tester-module` branch to validate Rack components, custom controls, ports, lights, and panel layout.

It is intentionally included in this branch for UI/component testing. It is not intended to be part of the main user-facing module collection.

---

## Purpose

- Check standard Rack knobs, switches, buttons, ports, and lights.
- Check custom TeknoLogical component assets.
- Verify panel layout and scaling while developing new UI elements.

---

## Notes

- TL-tester does not process audio or CV in a musical way.
- All lights are held on so component visibility can be checked quickly.
- Empty parameter and input names are expected because this module is a visual test fixture.
